Inference-Time Language Model Alignment via Integrated Value Guidance

Findings of EMNLP 2024

IVG combines fine-grained token steering with longer-horizon candidate selection, using two complementary value functions learned from the same preference data.

01

Research question

How can smaller preference models align a frozen target LLM at inference time—without updating its parameters?

Granularity mismatch

Token-level signals are precise but myopic; sequence-level rewards see global quality but are difficult to apply during unfinished generation.

A

Local control

Adjust each next-token distribution with a dense preference signal.

B

Long horizon

Compare partial responses after a chunk of generation, not only one token.

C

Frozen target

Guide much larger target models without task-specific fine-tuning.
