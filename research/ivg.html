Inference-Time Language Model Alignment via Integrated Value Guidance

Findings of EMNLP 2024

Research question

How can a frozen language model be aligned at inference time using preference signals from smaller models, without fine-tuning the target model?

Core method

IVG integrates two complementary signals learned from the same preference data: a DPO-derived implicit value adjusts the token distribution at every decoding step, while an explicit prefix value scores partial responses during chunk-level beam search. The combination provides fine-grained local steering and longer-horizon candidate selection.

Key results

  • Improved Mistral-7B-Instruct-v0.2 on AlpacaEval 2.0 from 19.51% to 26.51% length-controlled win rate.
  • Improved Mixtral-8×7B-Instruct-v0.1 from 25.58% to 33.75%.
  • Used 7B-scale value models to guide frozen targets up to Llama-2-70B and Mixtral-8×7B.
